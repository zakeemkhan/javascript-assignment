# JavaScript Assignment

Core JavaScript exercises covering conditionals, type conversion, functions, objects and loops.

## Files

| File | Topic |
|------|-------|
| `question1.js` | Grades with a `switch` statement, pass/fail with a ternary |
| `question2.js` | String-to-number conversion, truthy and falsy values |
| `question3.js` | `greetingBot` function using logical operators and template literals |
| `question4.js` | `post` object, `addLike()` method, object destructuring |
| `question5.js` | Spread operator, star pyramid with a `for` loop, countdown with a `while` loop |
| `index.js` | Runs all five questions |

## How to run

Requires [Node.js](https://nodejs.org).

```bash
node index.js        # run everything
node question1.js    # or run a single question
```
